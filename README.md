# Fund Navigator AI

Build an AI-agent-driven investment fund operations and governance web app. Include fund setup with strategy and risk limits, multi-tier agent autonomy settings (autonomous, human approval required, prohibited), multi-agent workflow pipeline (Research, Portfolio, Risk, and Trading agents), real-time monitoring of fund metrics and agent operations, an exception triage inbox for human review with explainable context and action overrides, and an audit trail of all agent and human decisions.
